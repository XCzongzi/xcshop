# Minecraft 物品资源导入

设置 → 物品信息中选择 Java 原版版本，点击“导入并启用”。正式版从 1.13 开始；版本选择器默认隐藏测试版，可手动显示。刷新列表会读取 Mojang 官方版本清单，所以新增版本不需要等待第三方更新物品表。

本地客户端 JAR 和 Java 路径均可留空。客户端留空时下载官方文件；提供本地文件时先与所选版本的官方 SHA-1 校验。老版本 JAR 没有内置版本信息时，可填写版本号。Java 会从 PATH、JAVA_HOME 和常见的已安装运行时目录查找；优先使用官方元数据要求的主版本。若更高版本 Java 不能运行旧版生成器，应明确选择对应运行时。程序不修改系统 Java。

## 数据来源与流程

1. 从 `https://piston-meta.mojang.com/mc/game/version_manifest_v2.json` 获取版本列表，再按其校验值下载版本元数据。
2. 获取并校验对应的官方客户端和服务端 JAR。
3. 运行服务端自带的 `net.minecraft.data.Main --reports`。支持旧式单 JAR 的 classpath 启动，以及打包服务端的 `bundlerMainClass` 启动。
4. 从注册报告获取完整物品 ID。1.13 的旧式 `items.json` 与新版 `registries.json` 分别处理；1.20.5 起的默认组件，以及 26.1 起按物品输出的默认组件会合并进清单。
5. 使用客户端资源渲染默认物品状态。渲染失败仍保留物品条目，分别标记默认图标、近似预览、缺少图标。
6. 在暂存目录完成整包写入后，原子更新 `active.json`，切换整个版本。

完整列表指该版本注册的物品类型，包含空气注册项（设置列表隐藏空气）。不会枚举所有药水效果、染色、附魔、玩家皮肤等物品堆叠变体。基岩版、模组包和修改后的客户端不在此导入流程的支持范围。

## 存储与失败处理

应用目录的 `assets/minecraft/items/` 包含：

| 路径 | 用途 |
| --- | --- |
| `active.json` | 当前生效的完整资源包指针 |
| `packs/<客户端哈希>-r<渲染器版本>-<唯一标识>/catalog.json` | 版本、来源、默认组件、渲染状态与完整物品清单 |
| `packs/.../assets/minecraft/` | 对应版本的图标 |
| `cache/` | 官方元数据、校验后的下载、生成的报告和资源包索引 |
| `custom-items.json`、`assets/<命名空间>/` | 独立保存的自定义物品与图标 |
| `import-settings.json` | 上次填写的导入选项 |

切换页面不终止导入；取消会停止下载或数据生成器。清单生成、文件校验、解压或渲染流程失败时，不修改当前资源指针。已生成资源包可直接切换；“重新生成已有图标”用于修复图标或应用新版渲染器。旧的本地 `items.json` 只用于迁移前显示，不再从 ForeverIds 下载数据。

首次导入需要联网获取官方元数据与所需文件。元数据、下载及资源包均已缓存时，可离线再次导入或切换。刷新版本列表失败时使用已有缓存并显示提示。

## 渲染兼容范围

渲染器支持旧式模型继承、默认状态覆盖选择、多层生成贴图、动画默认帧、图集别名/裁切/调色板，以及新版条件、选择、范围和组合模型。特殊物品使用独立的本地几何预览。

近似预览会在条目中说明原因，例如旧版刷怪蛋的代码内着色、环境相关指南针状态、特殊模型几何、子模型变换或组合模型合成。未知未来模型类型保留物品条目并显示缺失原因。此流程保证已识别报告中的物品清单完整，不承诺所有历史或未来客户端的图标都与游戏逐像素一致。

新增版本若沿用已支持的报告与资源格式，可直接导入；更改生成器入口或报告结构时需要更新 `MinecraftGameData.cpp`，新增显示格式则更新 `MinecraftItemRenderer.cpp`。无法识别报告时停止导入，避免将资源目录扫描结果误当完整注册表。

## 验证

配置 `XCSHOP_BUILD_TESTS=ON` 后运行 CTest。`minecraft_import_tests` 覆盖报告解析、版本排序、路径校验、缓存启用、取消与失败隔离，以及多层贴图、动画、GUI 状态和图集调色板。`minecraft_items_ui_smoke` 验证设置页加载、筛选、自定义图标独立保存和页面重建，并输出宽窄两种布局截图。

可选的真实官方资源集成检查：

```powershell
minecraft_import_tests.exe --import 1.13 <独立测试资源目录> <java.exe路径>
minecraft_import_tests.exe --import 1.21.4 <独立测试资源目录> <java.exe路径>
minecraft_import_tests.exe --import 26.3 <独立测试资源目录> <java.exe路径> --rebuild
```

集成检查会下载对应版本官方游戏文件，并运行其数据生成器。使用独立目录，避免切换日常使用的资源。

本次使用真实官方文件验证的结果如下。物品数包含空气；空气不生成图标。

| 版本 | 注册物品 | 默认图标 | 近似预览 | 缺少图标 |
| --- | ---: | ---: | ---: | ---: |
| 1.13 | 785 | 667 | 117 | 0 |
| 1.19.4 | 1228 | 1078 | 149 | 0 |
| 1.20.5 | 1330 | 1177 | 152 | 0 |
| 1.21.4 | 1385 | 1291 | 93 | 0 |
| 26.3 | 1658 | 1542 | 115 | 0 |

这些检查覆盖主要格式边界，并非逐一验证每个历史补丁版或测试版。
