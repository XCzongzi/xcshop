## 来源分类

| 内容 | 作者确认的来源 | 许可记录方式 |
| --- | --- | --- |
| 背景图片，包括 `assets/backgrounds/` 内的游戏画面 | 作者自己在 Minecraft 游戏中截取 | 保留截图来源说明；截图中的 Minecraft 及其他既有内容的相关权利分别保留，不统一标为完全由作者原创或统一改授 GPL |
| Minecraft 风格 GUI 图片，包括 `assets/minecraft/gui/` 内两张提示框和六张容器图片 | 从 Minecraft 游戏 JAR 内的资源文件获取 | 原版资源单列；具体游戏版本、JAR 内路径和实际使用/分发依据继续按文件补充 |
| 其他界面图标及对应设计源文件 | 作者原创 | 不包括社媒品牌标识、上行所述游戏资源和背景截图；原创图标需要明确素材许可，不能套用品牌图标的来源声明 |
| `assets/gui/brands/` 中的平台图标 | GitHub 官方素材、Simple Icons、爱发电官网 | 详见[品牌来源记录](../../assets/gui/brands/SOURCES.md)，保留适用的品牌规范和版权/许可说明 |
| `kits/` 中内置套件 | 作者原创与 AI 辅助制作 | 与闭源构建器实现、编辑器代码分开记录；套件自身的具体许可证尚未另行选择 |
| 材料包/数据包逻辑 | 作者原创 | 后续明确材料正文如何随生成结果分发，避免无意要求用户自己的数据包采用未选择的许可 |

作者提供的是上述分类级说明；每张截图及原版 GUI 对应的具体游戏版本、提取路径等细节尚未逐项提供，可在发布相应文件时补充。
