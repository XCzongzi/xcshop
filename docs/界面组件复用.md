# 界面组件复用

新增界面优先组合以下公共组件，业务页面只负责数据与操作。

| 场景 | 公共实现 | 约定 |
| --- | --- | --- |
| 确认、保存、创建等操作 | `ActionButton` | 主操作设 `primary: true`，危险操作设 `destructive: true`；文字随主题色计算对比度，不再固定颜色。 |
| 模态弹窗 | `PopupFrame` | 统一遮罩、标题、底部圆角（顶部直角）、阴影和动画；在 `onAboutToOpen` 初始化字段，调用 `close(result)` 返回结果。 |
| 页面内常驻弹窗 | `PopupFrame` | 设置 `visible: false`、`manageVisibility: true`；需要点击遮罩关闭时设置 `closeOnScrim`。 |
| 选择框 | `ChoiceBox` | 选项使用 `value`、`label`，分组通过 `group`、`groupLabel` 提供；业务名称不写入通用控件。 |
| 设置页面 | `SettingsSection` + `SettingsCard` | 页面容器统一标题、滚动与卡片间距；卡片内容坐标相对于内部留白区域。 |
| 滚动区域 | `XCScrollView` / `XCScrollBar` | 保持统一的主题、悬停、拖动状态。旧 `ScrollBar` 接口保留用于已有的偏移同步调用。 |
| 文本输入背景 | `InputBackground` | 单行、多行与选择框共用焦点边框及动画。 |
| 可调整高度的编辑器 | `ResizableEditor` | 共用内容同步、提交、尺寸按钮和高度动画；高亮与实际输入控件由子组件提供。 |
| 元素选择 | `ElementSelectionBase` | 共用选择状态、校验、拖放、SignalBus 监听与生命周期；完整和紧凑组件只提供布局。 |
| 元素与数值连接行 | `ElementConnectionRow` | 通过 `selectionType`、`valueKey` 定制业务字段；列表位移使用 `AnimatedListRemoval`。 |

`ComboBox`、`GlobalChoiceBox`、`SettingsActionButton` 保留兼容接口，其行为和样式已转交公共实现。

主题实际颜色与设置预览统一读取 `js/ThemeCatalog.js`；Minecraft 文本的预设颜色统一读取 `js/MinecraftTextColors.js`。

验证入口：启用 `XCSHOP_BUILD_TESTS` 后运行 CTest。`shared_ui_smoke` 覆盖公共组件交互、主题预览、弹窗返回值与焦点、连接行删除及中途切换分组。
