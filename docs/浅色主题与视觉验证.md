# 浅色主题与视觉验证

浅色模式使用六套独立的有色底盘：云白（灰蓝）、冰川（冰蓝）、薰衣草（紫）、薄荷（绿）、羊皮纸（暖黄）、樱粉（粉）。每套主题分别定义侧栏、卡片、输入框、弹出层、交互状态和文字颜色，避免把所有容器染成同一种灰色或接近白色。

## 配色职责

配色数据在 `js/ThemeCatalog.js`，运行时入口为 `qml/Colors.qml`。

| 颜色 | 用途 |
| --- | --- |
| `background_n` / `background` | 窗口底色、原有背景遮罩 |
| `panel` | 导航侧栏和元素管理器 |
| `card` | 内容卡片及其内部表面，沿用 `panel` 的色调，仅略微提亮 |
| `input` | 输入框、下拉选择框、元素连接框 |
| `popup` | 弹窗、菜单及下拉列表的磨砂底色 |
| `control` / `fired` / `pressed` | 普通按钮、悬停、按下和选中状态 |
| `text` / `banned` / `placeholder` | 正文、辅助说明、输入占位文字 |
| `outline` | 边界与分隔线的色相 |
| `border` | 用户选择的原始强调色、装饰与状态标识 |
| `accentText` / `accentFill` / `accentContent` | 可读的强调色小字、主按钮背景及文字 |
| `selection` / `selectedRow` / `selectionContent` | 文本选择、已打开文件、勾选标记与样式开关文字 |
| `ambientAccent` | 背景渐变和光效的低饱和色调 |

强调色小字由用户的原始强调色派生，存储的强调色保持不变。图片背景下，正文、说明、占位文字和状态文字使用更深的墨色。Minecraft 内容预览保持游戏原有颜色，用户编辑的文本颜色不受界面主题改写。

颜色职责通常继承对应旧颜色的 alpha；浅色 `panel` 的不透明度单独调整为 62%，用于减轻侧栏和文件栏对背景的遮挡。其余控件透明度、背景透明度、模糊、阴影参数、布局与交互流程保持原值。单色图标使用 Qt Controls 的 `IconImage` 着色，软件渲染和 GPU 渲染均可显示，不依赖额外的着色效果图层。

## 自动验证

开启 `XCSHOP_BUILD_TESTS` 后构建，运行：

```powershell
ctest --test-dir build -R "light_theme_ui_smoke|shared_ui_smoke|dropdown_ui_smoke|operations_ui_smoke|editor_startup_smoke" --output-on-failure
```

`light_theme_ui_smoke` 覆盖：

- 六套浅色主题和五种强调色，以及黑、白自定义强调色。
- 合成透明底色后的正文、说明、占位、选中文字、链接、主按钮和勾选标记对比度（至少 4.5:1）。
- 从真实截图中取样，检查纯色与默认图片背景上的说明文字、输入占位文字、八类语法高亮颜色，以及关闭图标的实际着色。取样坐标包含 Windows 显示缩放比例。
- 下拉列表打开与关闭、弹窗，以及商品、界面、代价、展示、项目总览、设置、开始、创建项目、关于九类页面。
- 图片背景下的商品页、设置页，以及 680 × 760 的商品页、设置页。
- 原有材料 alpha 和深色主题的颜色职责回退。

每次完整运行生成 102 张截图。软件渲染截图保存在 `build/theme-qa/software/`，GPU 截图保存在 `build/theme-qa/gpu/`。GPU 验证使用 `QT_QPA_PLATFORM=windows`、`QT_QUICK_BACKEND=rhi`、`QSG_RHI_BACKEND=d3d11`、`QSG_RENDER_LOOP=basic` 运行 `appxcshop --light-theme-ui-smoke`，用于检查软件渲染不支持的渐变、磨砂和模糊效果。软件测试窗口放置在屏幕外；GPU 测试窗口保持在桌面底层且不获取窗口焦点，以便图形驱动实际提交渲染帧。

图片背景的像素测试针对项目自带的默认背景及现有模糊设置；任意自定义壁纸的局部明暗仍需在实际页面中检查。测试数据和设置写入临时项目，避免修改用户项目或用户设置。

修改测试场景时，可通过测试构建专用的 `XCSHOP_THEME_TEST_FILE` 环境变量加载本地测试 QML；默认仍使用编译进程序的测试资源。
