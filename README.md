# xcshop

面向 Minecraft Java 版的商店数据包编辑器。用可视化界面组织商店布局、商品、代价和展示文本，再调用独立构建器校验、生成数据包。

这是一个由玩家维护的早期社区项目，开发过程中大量使用 AI 辅助编写与修改。欢迎反馈问题和提交改进，更新与维护随作者个人时间安排。使用真实项目、生成或替换数据包前，请先备份。

## 可以做什么

- 用 UI、Item、Cost、Display 四类可复用元素组织商店。
- 编辑容器槽位、物品、代价、操作、宏参数及文本样式，预览界面和提示文本。
- 配置构建套件和独立构建器，查看构建日志、错误与警告。
- 从本地游戏或在线入口导入基础 Minecraft 物品资料和图标，切换已有资源版本。
- 使用深浅主题、自定义背景和编辑字体。

Minecraft 版本适配由所选套件、构建器和资源格式共同决定。当前编辑器项目数据版本为 `0`；内置 Alpha r0 套件面向 Java 26.3，并有其自身的容器限制。项目数据版本不等于 Minecraft 的游戏版本或 `DataVersion`。详细边界见[构建器接入](docs/构建器接入.md)和[物品资源导入](docs/Minecraft物品资源导入.md)。

## 使用发布包

1. 完整解压发布包到当前用户有写入权限的目录，保留程序旁的依赖、`kits/`、`builder/` 和资源目录。
2. 启动 `appxcshop.exe`；如果采用 CMake 默认安装布局，程序在 `bin/` 下，以实际发布说明为准。
3. 在设置中检查构建器及套件路径，再创建项目、编辑和构建。

当前程序在自身目录保存设置、默认项目和资源缓存。便携使用时请放在可写目录。迁移程序前同时备份项目、设置、自定义资源及自己修改过的套件。

程序启动后会在后台通过 GitHub Releases 检查编辑器正式版本；断网、请求失败或尚无正式版本时不弹窗。发现新版本后可选择“查看更新”打开发布页面，或“关闭”并记住该版本（保存在程序目录的 `update-state.ini` 中），同一版本之后不再自动提醒。关于页的软件版本后仍显示可点击的“[有新版本]”，可以随时重新打开提示；软件不会自动下载或安装更新。

发布者可以预装某个明确版本的渲染图标，使该版本无需首次导入即可使用。具体预装版本以该次发布说明为准；没有预装或需要其他版本时，可使用资源导入功能。Java 仅在运行游戏数据生成器等相关导入流程时需要，程序不自动安装 Java。

## 编译与测试

项目配置声明 CMake 3.16 起、C++17 和 Qt 6.8 起；实际 CMake 版本还需满足所选 Qt 套件的要求。现有开发配置使用 Windows x64、Qt 6.11.2、MinGW 13.1.0 和 Ninja，本机安装有 CMake 3.30；其他组合需要自行验证，Qt 与编译器套件必须匹配。

完整步骤、资源准备和测试命令见[构建说明](docs/构建说明.md)。Git 忽略规则已放行构建所需的八张 Minecraft GUI 图片和内置 Alpha r0 套件原始文件；将这些文件随相应源码版本提交后，克隆即可取得这些构建输入。物品导入图标、下载缓存、个人配置和其他本地套件仍被忽略。文件范围与校验值见[资源清单](docs/release/资源清单.md)。
